# NHÂN VẬT BÍ ẨN – Sửa nhiều học sinh và chơi lại

- Mỗi câu diễn ra **30 giây** theo đồng hồ máy chủ, không kết thúc sớm chỉ vì 1 hoặc 2 học sinh đã trả lời.
- Học sinh thứ 3 (hoặc vào muộn) vẫn có thể trả lời trong thời gian còn lại.
- Mỗi học sinh gửi tối đa một đáp án mỗi câu.
- Đáp án/nhạc chỉ mở khi hết thời gian, giáo viên không thể vô tình bỏ qua câu đang thi.
- Hết câu 4/4, giáo viên bấm **Chơi lại**: màn hình trở về **Sẵn sàng chơi / Bắt đầu**, xóa điểm và thời gian, giữ danh sách học sinh trong phòng.
- Bộ ZIP chứa toàn bộ server, giao diện, ảnh, nhạc. Có thể chỉ thay `server.js` và `public/index.html` trên GitHub.

## Đưa lên Render

Commit hai file sửa lên repository GitHub, chọn Render → Manual Deploy → Deploy latest commit. Dùng phòng mới để kiểm tra.

**Lưu ý:** Render phải cập nhật cả hai file để nút Chơi lại khớp với cơ chế máy chủ.
